Small utilities I built to make everyday computer tasks easier.

SizzlerCleans

A lightweight Windows batch script that instantly tidies any folder by sorting loose files into category folders. No installation, no setup — just drop it in a folder and run it.

Videos Photos Documents Txt Files Music Zip Apps Others

How to use it

  1. Download the .bat file using the button below and place it in the folder you want to clean (for example, your Downloads folder).
  2. Double-click SizzlerCleans.bat — a command window opens and sorts the files automatically.
  3. Files move into folders beside the script based on their type (for example, .mp4 → Videos, .jpg → Photos, .pdf → Documents). Anything unrecognized goes into Others.
  4. Files that are still downloading (.crdownload, .part, .tmp) are left untouched.
  5. When you see "Done! Your folder has been organized.", press any key to close the window.

Note: it only organizes files in the folder it is placed in — it does not touch subfolders. Windows only.

SizzlerTempFree

A Windows cleanup script that clears temporary files from your user TEMP folder and the Windows Temp folder. It asks for confirmation before deleting anything and skips files that are currently in use.

User TEMP Windows Temp Asks confirmation Skips locked files

How to use it

  1. Download the .bat file using the button below and save it anywhere on your computer.
  2. Double-click SizzlerTempFree.bat — a command window opens and asks "Continue with cleanup? (Y/N)".
  3. Press Y to start. It cleans your user TEMP folder first, then the Windows Temp folder if permitted.
  4. Files being used by Windows or other apps are skipped automatically, so some temp files may remain.
  5. When you see "Cleanup finished.", press any key to close the window.

Note: it only targets temp folders — your documents, downloads and photos are not touched. Press N at the prompt to cancel without changing anything. Windows only.
